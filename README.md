# 基于多模态数据的青少年抑郁早期筛查算法研究

> Research on Early Screening Algorithm for Adolescent Depression Based on Multimodal Data

本项目面向青少年心理筛查场景，研发一套**语音、视觉、文本三模态融合**的青少年抑郁智能筛查系统，以无创、低门槛、高客观性的技术方案，实现青少年抑郁风险的早期识别与初步分型。

## 项目背景与意义

当前我国青少年心理健康问题呈高发、低龄化态势，《中国国民心理健康发展报告》显示 **10~16 岁青少年抑郁风险检出率达 14.8%**，已成为影响青少年健康成长的重要公共卫生议题。

传统抑郁筛查模式依赖自评量表与专业临床访谈，存在两大核心痛点：

1. **主观量表失真**：青少年普遍存在心理病耻感，自评时刻意隐瞒真实情绪，漏诊率高；
2. **基层资源匮乏**：基层学校与欠发达地区专业心理师资、精神医疗资源供给严重不足，规模化常态化早筛难以落地。

本项目通过构建语音、文字、图像三模态融合的青少年抑郁症智能分析模型，以无创、低门槛、高客观性的方案实现抑郁风险早期识别与初步分型，深度契合《"健康中国2030"规划纲要》、教育部《全面加强和改进新时代学生心理健康工作专项行动计划》等政策要求，推动青少年心理筛查从"主观自评"向"多模态客观量化"升级。

## 痛点与解决方案

### 行业四大痛点

| 痛点 | 具体表现 |
| --- | --- |
| 主观量表失真 | 青少年因心理病耻感刻意隐瞒情绪，漏诊率高 |
| 专业资源匮乏 | 基层校医、心理师资缺口大，常态化筛查难落地 |
| AI 产品适配差 | 现有模型多基于成人数据训练，对青少年隐蔽情绪识别率低 |
| 部署成本过高 | 医疗级设备依赖专用硬件，难以下沉校园、家庭普惠场景 |

### 解决方案

构建 **"数据合规预处理 → 分模态弱情绪特征提取 → 跨模态自适应注意力融合 → 抑郁亚型多分类识别 → 端侧轻量化隐私部署"** 全链路技术体系，开发**纯软件移动端小程序平台**，无需专业硬件，依托普通手机即可完成无感化、匿名化抑郁风险检测。

## 技术架构

```
多模态数据输入
      ↓
数据预处理（清洗 / 脱敏 / 标准化）
      ↓
单模态特征提取
      ↓
多模态注意力融合
      ↓
结果筛查输出（风险分级 / 亚型判别 / 可解释报告）
```

### 单模态特征提取方案

| 模态 | 涉及技术 |
| --- | --- |
| 语音 | Wav2Vec2、OpenSmile |
| 视觉 | 3D-CNN、OpenFace |
| 文本 | BERT、LIWC |

### 全链路流程

数据采集 → 标准化预处理流水线 → 分模态特征提取 → 跨模态注意力融合网络 → 抑郁亚型分类与结果输出

## 核心算法创新

### 1. 面向青少年优化的跨模态注意力融合算法

- 分别搭建语音、人脸、文本独立自注意力分支，精准挖掘青少年隐性弱情绪特征；
- 增设跨模态交互注意力层，依据被测者年龄、实时表达状态动态分配模态权重；
- 平衡青少年场景下模态信息不均衡难题，提升模型 AUC 指标，降低漏诊误诊概率。

### 2. 弱情绪小样本特征提取优化方法

- 语音端：改良 Wav2Vec2，新增短停顿、低语速、低沉基频等青少年专属抑郁韵律提取分支；
- 视觉端：优化 3D-CNN，强化细微面部动作、短时微表情时序捕捉能力；
- 文本端：微调 BERT 适配青少年网络短句表达，依托 LIWC 拓展青少年专属情绪词库；
- 引入 MixUp、模态掩码数据增强算法扩充小样本数据集，提升泛化能力。

### 3. 临床导向抑郁亚型多分类识别方案

- 在融合网络后端新增临床亚型分类头，同步完成抑郁四级风险分级、隐匿性抑郁、反应性抑郁多任务识别；
- 搭建特征-亚型关联映射模块，配套可解释分析算法，自动定位判定依据对应的关键语音片段、微表情帧、负面文本关键词，实现筛查结果可追溯、可解释。

### 4. 端侧轻量化 + 隐私安全一体化工程实现

- 采用模型剪枝、8bit 量化、知识蒸馏多级压缩方案，依托 ONNX Runtime Mobile 实现手机本地离线推理；
- 全链路端侧隐私防护：数据采集阶段完成人脸模糊、语音声纹剥离、文本敏感信息匿名化脱敏；全部特征提取、模型推理在设备本地完成，原始生物数据不离开用户终端。

## 系统模块设计

### 前端交互模块

| 子模块 | 功能说明 |
| --- | --- |
| 数据采集模块 | 引导用户完成语音录制、面部拍摄、文本填写的流程 |
| 报告生成模块 | 生成结构化筛查报告，包含风险等级、各维度得分、可解释性分析、建议措施 |

### 智能筛查模块

| 子模块 | 功能说明 |
| --- | --- |
| 多模态融合分类网络 | 系统核心，将三类模态特征通过跨模态注意力机制融合，输出抑郁风险等级 |
| 注意力加权模块 | 自动学习各模态的重要性权重，针对不同个体动态调整 |
| 抑郁风险分级输出 | 输出四级风险：正常 / 轻度 / 中度 / 重度 |
| 可解释性分析模块 | 输出特征重要性排序、关键帧 / 关键语音段定位、文本关键词高亮 |
| 模型轻量化部署模块 | 通过剪枝、量化、知识蒸馏压缩模型体积，适配移动端 / 边缘设备部署 |

### 单模态特征提取模块

| 子模块 | 功能说明 |
| --- | --- |
| 语音特征提取 | 提取韵律特征（语速、停顿、基频等）、音质特征、频谱特征 |
| 视觉特征提取 | 提取面部动作单元、微表情时序变化、头部姿态、眼神特征 |
| 文本特征提取 | 提取语义向量、负向情绪词频、第一人称占比、语义连贯性 |

### 数据处理模块

| 子模块 | 功能说明 |
| --- | --- |
| 数据采集 | 采集三类原始数据：语音、面部视频、行为和文本 |
| 数据清洗 | 去噪、裁切、标准化采样率和分辨率、缺失值处理 |
| 数据脱敏 | 人脸模糊化、语音去身份特征、文本匿名化，符合隐私合规要求 |
| 标准化数据集 | 统一格式、划分训练 / 验证 / 测试集，形成可复用的数据集资产 |

## 技术壁垒

1. **面向青少年弱情绪的三模态自适应注意力融合算法**：区别于通用静态权重融合方案，分层动态跨模态注意力融合网络专门适配青少年群体情绪特征；
2. **小样本下青少年抑郁亚型多分类可解释识别**：引入数据增强与迁移学习缓解青少年样本稀缺，参照青少年心理诊疗标准实现风险分级与亚型判别，筛查结果可追溯、可解释；
3. **端侧轻量化 + 未成年人全链路隐私安全一体化工程方案**：多手段模型压缩 + 全链路端侧隐私防护，低成本实现规模化普惠落地。

### 项目开发难度

项目开发难度中等偏上，核心难点集中在：

1. **算法优化难度高**：青少年抑郁情绪特征微弱、隐性，跨模态动态权重融合调参复杂，小样本训练易过拟合；
2. **数据隐私合规约束严格**：涉及未成年人敏感生物数据，需自主开发全流程脱敏、匿名化逻辑；
3. **落地性能平衡难度大**：需平衡模型体积、推理速度与筛查准确率，并完成多机型、多场景适配。
